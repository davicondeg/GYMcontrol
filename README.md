# GYMcontrol

Aplicativo mobile local-first para consultar cargas de exercícios e acompanhar hábitos diários.

## Desenvolvimento

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npm start
```

Valide o projeto:

```bash
npm run typecheck
npm run lint
```

Os dados do MVP são armazenados localmente com SQLite no dispositivo.
