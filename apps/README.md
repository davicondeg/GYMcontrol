# Aplicações do ecossistema Jhonny

Este diretório reúne aplicações independentes mantidas no mesmo repositório.

- `financeiro`: protótipo inicial do gestor financeiro, importado para evolução.

O GymControl permanece temporariamente na raiz para preservar o processo de
publicação existente. A aplicação financeira não deve importar arquivos de
`src/` nem depender da navegação do GymControl.
